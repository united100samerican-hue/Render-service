# Social Media Service

خدمة مستقلة لمصادر الوسائط الخارجية. المجلد يبقى `YouTube` حسب الهيكل المطلوب، لكن اسم الخدمة وواجهتها محايد: Social Media.

- yt-dlp لاستخراج YouTube/Shorts/Facebook وغيرها من المصادر التي يدعمها extractor.
- PyTgCalls للبث داخل المكالمة.
- VOD: تنزيل ومزج الفيديو والصوت محليًا لتحسين الثبات والـ seek.
- Live: استخدام stream مباشر إذا توفر stream موحد؛ إن لم يتوفر، نرفض تشغيل الفيديو المباشر بدل تشغيل شيء غير صحيح. يمكن إضافة relay لاحقًا بدون تغيير بقية الطبقات.
- لا توجد Queue داخل Render؛ Worker/D1 سيكون مصدر قائمة التشغيل الوحيد عند التفعيل.
- لا توجد أي تعديلات على audio أو tiktok في هذه المرحلة.
